## 1. Архитектура и Стек Технологий

- **Frontend**: React 18 (TypeScript), Vite 5.
- **Стилизация**: Tailwind CSS, Vanilla CSS переменные, Apple Human Interface Design (Glassmorphism, Backdrop Blur, Cupertino Shadows, скругления `rounded-2xl`).
- **Иконки & Анимации**: `lucide-react`, `framer-motion`, `canvas-confetti`.
- **Графики**: `recharts` (AreaChart с плавными градиентами, BarChart, Donut PieChart).
- **Формы и Валидация**: `react-hook-form`, `zod`, `@hookform/resolvers/zod`.
- **Управление состоянием и кэширование**: `@tanstack/react-query` (автоматическая инвалидация кэша и реактивное обновление UI), React Context API (`AuthContext`, `DataContext`, `ThemeContext`).
- **Интернационализация (i18n)**: `i18next`, `react-i18next` (100% покрытие 3 языков: Русский 🇷🇺, English 🇺🇸, O'zbekcha 🇺🇿).
- **Слой данных**: Гибридный сервис-провайдер с автоматическим переключением:
  - **Режим Supabase**: PostgreSQL, Row Level Security (RLS), Cookie-based сессии.
  - **Демо/Локальный режим**: LocalStorage + Cookie Storage с полным набором реалистичных демо-данных.

## 2. Исправленные Ошибки

В ходе аудита и тестирования кодовой базы были обнаружены и устранены следующие ошибки:

1. **Исправлен сдвиг даты из-за таймзон (Timezone Off-by-one Day Bug)**:
   - **Где**: `src/utils/formatters.ts` (`formatDate`).
   - **Проблема**: Конструкция `new Date("YYYY-MM-DD")` парсила дату в формате UTC. В часовых поясах с отрицательным или отличным смещением отображался предыдущий день (например, 30 число вместо выбранного 31).
   - **Решение**: Добавлен точный парсинг строковых дат `YYYY-MM-DD` по локальным компонентам (`new Date(year, month - 1, day)`), гарантирующий корректный день в любом часовом поясе.

2. **Исправлена логика пополнения целей (`goalService.deposit`)**:
   - **Где**: `src/services/goalService.ts`.
   - **Проблема**: При включенном Supabase функция пополнения вызывала `goalService.getAll('')` с пустым `userId`, из-за чего цель не находилась (`Goal not found`).
   - **Решение**: Переписана на прямой точечный запрос к базе по `id` (`supabase.from('goals').select('*').eq('id', id).single()`) с корректным fallback на локальное хранилище.

3. **Исправлена реактивная валидация кастомных компонентов в формах**:
   - **Где**: `src/components/forms/ExpenseForm.tsx`, `IncomeForm.tsx`, `GoalForm.tsx`, `BudgetForm.tsx`, `DatePicker.tsx`.
   - **Проблема**: При выборе даты в `DatePicker` или категории/метода в кастомном `Select` метод `setValue` вызывался без флагов `{ shouldValidate: true, shouldDirty: true }`. Если до этого поле было подсвечено ошибкой, сообщение об ошибке не исчезало сразу после выбора значения.
   - **Решение**: Добавлены флаги `shouldValidate: true` и `shouldDirty: true` во все формы, а в `DatePicker` улучшена обработка событий кнопки очистки для исключения некорректного всплытия клика.

## 3. Подробное Описание Разделов и Функций

### 3.1. Аутентификация и Демо-режим
- **Страница входа (`/login`)**:
  - Вход по Email и Паролю.
  - Карточка **"Мгновенный Демо-доступ" (Instant Demo Access)**: один клик позволяет протестировать весь функционал без регистрации.
  - Переключатели темы и языка прямо на экране входа.
- **Страница регистрации (`/register`)**:
  - Создание аккаунта (Имя, Email, Пароль).
  - Валидация обязательных полей.
- **Защита маршрутов (`ProtectedRoute` / `PublicRoute`)**:
  - Автоматический редирект неавторизованных пользователей на `/login`.
  - Автоматический редирект авторизованных пользователей с `/login` на `/`.

### 3.2. Обзор (Dashboard) — Главная страница (`/`)
- **Герой-секция "Текущий баланс"**:
  - Крупное отображение текущего чистого баланса (Доходы − Расходы).
  - **Умный вердикт финансового здоровья**:
    - *Отличное состояние* (Норма сбережений ≥ 30%).
    - *Стабильный баланс* (Норма сбережений 15–29%).
    - *Внимание к расходам* (Расходы превышают 85% дохода).
  - Панель быстрых действий: кнопки `+ Доход`, `+ Расход`, `+ В цель` открывают соответствующие модальные формы.
- **Сводные KPI-карточки**:
  - Доходы за месяц (с индикатором тренда).
  - Расходы за месяц (с индикатором тренда).
  - Норма сбережений (%) с суммой накоплений.
  - Активные цели (количество незавершенных целей).
- **Умные инсайты (Data Storytelling)**:
  - Автоматический расчет категории с наибольшим ростом или долей расходов.
- **График "Денежный поток" (Cash Flow Chart)**:
  - Интерактивный график площадей (AreaChart) с градиентной заливкой за последние 6 месяцев.
  - Тултип с детальными суммами при наведении.
- **Лента последних операций**:
  - Список последних 6 транзакций (доходы и расходы) с категорией, датой, заметкой и суммами.
  - Кнопка "Смотреть все" ведет в раздел расходов.

### 3.3. Доходы (Incomes) — (`/incomes`)
- **Статистические карточки**:
  - Всего доходов за выбранный список.
  - Средний чек дохода.
  - Общее количество операций.
- **Поиск и Фильтрация**:
  - Живой поиск по источникам/клиентам, заметкам и категориям.
  - Выпадающий список фильтрации по 8 категориям (Зарплата, Аванс, Премия, Фриланс, Продажи, Подарки, Инвестиции, Другое).
- **Список операций (Entity Card)**:
  - Каждая карточка содержит: сумму, категорию, цветной бейдж, источник, дату, заметку.
  - Кнопка редактирования (открывает модалку с предзаполненными данными).
  - Кнопка удаления (открывает модальное окно подтверждения).
- **Добавление дохода (`IncomeForm`)**:
  - Поля: Сумма, Категория, Источник/Клиент, Дата (через кастомный календарь DatePicker), Заметка.
- **Экспорт в CSV**:
  - Кнопка "CSV" мгновенно скачивает файл отфильтрованных доходов.

### 3.4. Расходы (Expenses) — (`/expenses`)
- **Статистические карточки**:
  - Всего расходов.
  - Средний чек расхода.
  - Среднедневной расход (рассчитан на 30 дней).
- **Поиск и Двойная фильтрация**:
  - Поиск по описанию и категории.
  - Фильтр по 17 категориям (Продукты, Кафе, Транспорт, Такси, Интернет, Связь, ЖКХ, Аренда, Кредиты, Подписки, Развлечения, Одежда, Здоровье, Дом, Путешествия, Питомцы, Разное).
  - Фильтр по способам оплаты (Карта, Наличные, Перевод).
- **Список операций**:
  - Карточки с индивидуальной цветовой кодировкой категорий, иконками, бейджами способов оплаты, кнопками редактирования и удаления.
- **Добавление расхода (`ExpenseForm`)**:
  - Поля: Сумма, Категория, Способ оплаты, Дата, Заметка.
- **Экспорт в CSV**:
  - Кнопка экспорта в CSV для анализа в Excel / Numbers / Google Таблицах.

### 3.5. Бюджеты (Budgets) — (`/budgets`)
- **Статистические карточки**:
  - Общий установленный лимит бюджета.
  - Фактически израсходовано за текущий месяц.
  - Оставшийся остаток средств.
- **Карточки категорий бюджета**:
  - Индикатор прогресса (Progress Bar) с динамическим цветом:
    - *Зеленый* — расход до 75% от лимита (статус "В норме").
    - *Желтый* — расход от 75% до 99% (статус "Внимание").
    - *Красный* — расход 100%+ (статус "Превышен").
  - **Умный расчет "Безопасно в день" (Daily Safe Spend)**: рассчитывает, сколько можно тратить в день до конца месяца, чтобы не выйти за рамки бюджета.
  - Редактирование лимита и удаление бюджета.
- **Добавление бюджета (`BudgetForm`)**:
  - Выбор категории расходов и задание суммы лимита на месяц.

### 3.6. Финансовые Цели (Goals) — (`/goals`)
- **Статистические карточки**:
  - Всего накоплено по всем целям.
  - Общая целевая сумма.
  - Количество завершенных целей (100%).
- **Карточки целей**:
  - Название, иконка, персональный цвет (из палитры 7 цветов).
  - Целевая сумма и текущий прогресс в валюте и процентах.
  - Прогресс-бар с кастомным цветом цели.
  - Дедлайн с умным счетчиком: "Осталось X дн.".
  - **Кнопка "Пополнить" (+ Внести)**:
    - Открывает быстрое диалоговое окно ввода суммы депозита.
    - При достижении 100% запускается праздничная анимация конфетти (`canvas-confetti`) 🎉!
  - Редактирование параметров цели и удаление.
- **Добавление цели (`GoalForm`)**:
  - Название, Целевая сумма, Начальная сумма, Дата дедлайна, Выбор акцентного цвета.

### 3.7. Финансовый Календарь (Calendar) — (`/calendar`)
- **Сетка календаря**:
  - Помесячный обзор с кнопками переключения «Предыдущий месяц», «Следующий месяц» и «Сегодня».
  - Подсветка текущего сегодняшнего дня.
  - В каждой ячейке дня:
    - Сумма доходов за день (+зеленый).
    - Сумма расходов за день (-серый/красный).
    - Маркер подписки (фиолетовая точка), если в этот день были списания за подписки.
- **Модальное окно дня**:
  - Клик по любому дню открывает подробную выписку всех доходов и расходов за выбранную дату с итоговым сальдо дня.

### 3.8. Аналитика и Статистика (Statistics) — (`/statistics`)
- **Фильтр периодов (Табы)**:
  - Этот месяц, Прошлый месяц, Этот год, Все время.
- **Сводные показатели**:
  - Доходы за период, Расходы за период, Процент сохраненных средств (Норма сбережений %).
- **График "Доходы vs Расходы" (BarChart)**:
  - Сравнительные столбчатые диаграммы помесячной динамики.
- **Круговая диаграмма "Структура расходов" (Donut PieChart)**:
  - Наглядное сегментирование расходов по категориям с цветовой палитрой и тултипами с процентами.
- **Таблица ТОП-5 категорий расходов**:
  - Ранжированный список категорий с наибольшими тратами, количеством операций и процентной долей в общем бюджете.

### 3.9. Профиль и Настройки (Profile) — (`/profile`)
- **Личные данные**:
  - Отображение аватара, имени и Email.
  - Редактирование имени пользователя.
- **Выбор основной валюты**:
  - Поддержка: `USD` ($), `EUR` (€), `UZS` (сум), `RUB` (₽).
  - Смена валюты мгновенно форматирует все числа, графики и карточки по всему приложению.
- **Выбор языка интерфейса**:
  - Русский 🇷🇺, English 🇺🇸, O'zbekcha 🇺🇿.
- **Выбор темы оформления**:
  - Светлая ☀️, Темная 🌙, Системная 💻.
- **Управление данными (Резервное копирование и Восстановление)**:
  - **Экспорт JSON**: скачивание полного бэкапа (доходы, расходы, бюджеты, цели).
  - **Экспорт CSV**: скачивание реестра транзакций.
  - **Импорт JSON**: загрузка ранее сохраненного файла с мгновенным обновлением интерфейса.
  - **Сброс демо-данных**: восстановление начальных демонстрационных данных с подтверждением.
- **Выход из аккаунта (Sign Out)**.

### 3.10. Глобальные Элементы Интерфейса
- **Боковое меню (Sidebar)**:

## 5. Инструкция по Подключению Базы Данных (Supabase)

Когда вы будете готовы подключить реальную облачную базу данных:

### Шаг 1: Создание проекта Supabase
1. Перейдите на [supabase.com](https://supabase.com) и создайте новый проект.
2. Откройте раздел **Project Settings -> API** и скопируйте:
   - `Project URL` (например: `https://xyzcompany.supabase.co`)
   - `anon public key` (например: `eyJhbGciOi...`)

### Шаг 2: Настройка переменных окружения
Создайте или отредактируйте файл `.env` в корне проекта:
```env
VITE_SUPABASE_URL=https://ВАШ_ПРОЕКТ.supabase.co
VITE_SUPABASE_ANON_KEY=ВАШ_ANON_КЛЮЧ
```

### Шаг 3: Выполнение SQL-миграции в Supabase SQL Editor
Откройте **SQL Editor** в консоли Supabase и выполните следующий скрипт:

```sql
-- 1. Таблица профилей пользователей
create table public.profiles (
  id uuid references auth.users on delete cascade primary key,
  email text,

-- Триггер для автоматического создания профиля при регистрации
create or replace function public.handle_new_user()
returns trigger as $$
begin
  insert into public.profiles (id, email, name, avatar_url, currency, locale, theme)
  values (
    new.id,
    new.email,
    coalesce(new.raw_user_meta_data->>'name', split_part(new.email, '@', 1)),
    null,
    'USD',
    'ru',
    'system'
  );
  return new;
end;
$$ language plpgsql security definer;

create or replace trigger on_auth_user_created
  after insert on auth.users
  for each row execute procedure public.handle_new_user();
```
